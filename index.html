About Me

I am a Full-Stack WordPress Developer based in Ahmedabad, Gujarat, dedicated to engineering scalable web applications and bespoke CMS architectures. My day-to-day focus centers around building modular PHP plugins, developing optimized child themes, and crafting high-performance AJAX search and data filtering interfaces.

With a strong academic foundation in Information Technology and Adobe UX Design certification, I combine software engineering standards with responsive front-end practices. I take pride in delivering maintainable codebases that integrate smoothly with Advanced Custom Fields (ACF Pro), REST APIs, and core WordPress functionality.

Beyond full-stack web development, my project experience spans computer vision systems built with Python/Flask, IoT automated monitoring solutions, and biometric Java applications. I am passionate about tackling technical challenges, learning modern frameworks, and crafting user-centric digital experiences.
